어둑 — Acceptance (검수 기준)
한국 전통설화 1인칭 공포게임 「어둑」 · 최종본 (2026.10)
완성을 어떻게 증명하는가. "어둑" Tasks의 각 작업이 끝났다고 판단하는 기준이다. 에이전트는 작업 후 해당 AC를 스스로 점검해 보고하고, 사람은 [수동] 항목을 확인한다.
0. 검수 안내
표기 | 뜻 | 판정 방법
[정상] | 정상 동작 (Happy Path) | 자동 테스트 또는 플레이로 확인
[예외] | 예외·에러·경계 상황 | 일부러 그 상황을 만들어 확인
[자동] | 자동 테스트 통과 조건 | Unity Test Framework에서 해당 테스트가 모두 녹색
[수동] | 사람이 하는 테스트 시나리오 | 적힌 대로 플레이해 결과 확인
허용 오차: 시간 ±0.1초, 거리 ±0.1m, 속도 ±0.05 m/s, 배율 ±0.05, 확률 ±5%p.
AC의 모든 항목이 통과해야 "완료"다. 하나라도 미통과면 "부분 완료".
"확인 불가"는 사유를 적고 사람에게 넘긴다.
