어둑 — 캐릭터 일러스트 프롬프트
한국 전통설화 1인칭 공포게임 「어둑」 · 구미 · 윤태호 · 윤민호 · 최종본
구미, 윤태호, 윤민호 세 인물의 캐릭터 일러스트 프롬프트다. 각 인물마다 외형 설정표, 기본 전신, 얼굴 클로즈업, 장면별 변형을 둔다. 모든 프롬프트는 공통 스타일과 금지어를 합쳐 둔 완성형이다.
사용법
제작 순서
윤태호 기본 전신을 먼저 뽑는다. 마음에 드는 얼굴이 나올 때까지 여러 장 뽑고 하나를 확정한다.
윤민호는 확정한 태호 이미지를 얼굴 참조(face reference)로 넣고 뽑는다. 두 사람이 공유하는 특징(아래 표)이 유지되는지 확인한다.
구미는 조작키 설정서의 구미 일러스트를 캐릭터 참조로 넣고 뽑는다. 장면 이미지들과 같은 인물로 보이게 하기 위해서다.
세 인물이 확정되면 턴어라운드 시트와 표정 시트를 같은 참조로 뽑아 3D 모델링용 자료로 쓴다.
